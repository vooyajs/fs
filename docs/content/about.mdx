# About

Vooya FS is maintained as part of the Vooya project family.

- [Vooya](https://github.com/vooyajs/vooya) builds browser components with Rust and
  WebAssembly while preserving framework-native integration.
- [Vooya Lab](https://github.com/vooyajs/vooya-lab) contains reproducible boundary,
  ABI, rendering, memory, and runtime experiments.
- [Vooya FS](https://github.com/vooyajs/fs) applies the same boundary-first,
  evidence-gated approach to native Node.js filesystem workloads.

The shared idea is not “rewrite everything in Rust.” It is to identify a coherent
workload, give it a typed boundary, measure the crossing cost, and keep the host
ecosystem in charge of the work it already does well.

Vooya FS was previously named Rush-FS. The new name makes that relationship clear
and gives the project a stronger product boundary: Node-compatible primitives plus
high-value batch extensions.
