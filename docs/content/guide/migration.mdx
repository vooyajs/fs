# Migrating from Rush-FS

The project and repository are now **Vooya FS**. The canonical npm package is
`@vooya/fs`.

## Planned import change

```diff
- import { glob, readdir } from '@rush-fs/core'
+ import { glob, readdir } from '@vooya/fs'
```

The Rust crate becomes `vooya_fs`, and the native binary basename becomes
`vooya-fs`. Repository and documentation links move to
`https://github.com/vooyajs/fs`.

## Package transition

1. Publish `@vooya/fs` only after CI, conformance, package installation, and
   platform artifact checks pass.
2. Verify fresh installs of the published package before changing legacy package
   metadata.
3. Mark `@rush-fs/core` and `rush-fs` deprecated with a direct migration message,
   while keeping every existing version installable.

npm deprecation displays a warning; it does not redirect one package name to
another. We do not publish a compatibility wrapper because the legacy packages
support Node.js 18 while `@vooya/fs` requires Node.js 22 or newer. A wrapper would
silently change the runtime requirement for users who update the old package.

## Behavioral review

The intended API surface remains familiar, but migration is not a promise of total
Node `fs` parity. Review the [API overview](/api), especially string-only paths,
missing callback/file-descriptor/stream APIs, and Vooya-only options such as
`concurrency`, `gitIgnore`, `lines`, and `scan`.
