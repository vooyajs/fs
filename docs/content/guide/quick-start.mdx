# Quick Start

The canonical package name planned for the next release is `@vooya/fs`. This
development branch is not yet published, so install from a checkout while testing
the migration.

```bash
git clone https://github.com/vooyajs/fs.git
cd fs
git switch feat/vooya-fs-next
corepack pnpm install --frozen-lockfile
corepack pnpm build
```

## Choose the right side of the boundary

Keep tiny, isolated operations in `node:fs`:

```ts
import { existsSync } from 'node:fs'

if (existsSync('./package.json')) {
  // The native bridge would add work here, not remove it.
}
```

Use Vooya FS when one call represents substantial or combined work:

```ts
import { glob, readdir, scan } from '@vooya/fs'

const entries = await readdir('./node_modules', { recursive: true })
const manifests = await glob('**/package.json', { cwd: './node_modules' })
const sources = await scan('./packages', {
  include: ['**/*.{js,ts,rs}'],
  exclude: ['**/dist/**'],
})
```

Every supported operation also has a synchronous variant such as `scanSync` or
`readdirSync`. Prefer async APIs in servers and interactive applications so native
work does not block the JavaScript thread.

## Verify a local checkout

```bash
corepack pnpm typecheck
corepack pnpm lint
cargo clippy --all-targets --all-features -- -D warnings
corepack pnpm test
corepack pnpm doc:build
```

Continue with the [execution model](/guide/execution-model) before selecting
operations solely from headline benchmark ratios.
